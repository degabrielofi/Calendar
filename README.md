## Sobre o Projeto

Calendário interativo desenvolvido com HTML, CSS e JavaScript, com tema visual inspirado nas cores da **bandeira brasileira** — verde, amarelo e azul. Exibe o dia, mês e ano atual de forma dinâmica.

O projeto foi construído como exercício de manipulação de datas com JavaScript e estilização criativa com CSS puro, explorando paletas de cores temáticas.

> Projeto desenvolvido em 2022, como parte da jornada de aprendizado em desenvolvimento front-end.

## Como Instalar e Rodar

```bash
# Clonar o repositório
git clone https://github.com/degabrielofi/Calendar

# Entrar na pasta
cd Calendar

# Abrir no navegador
start index.html
```
